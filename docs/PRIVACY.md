# 隐私说明草案

## 我们收集什么

为完成发布、展示和联系，可能收集：微信身份标识、群内昵称、用户主动填写的物品信息、图片和联系方式。楼栋信息为可选，不要求精确住址。

## 如何使用

- 展示物品信息
- 让邻里联系发布者
- 审核违规内容、处理举报
- 统计平台的匿名运营指标

## 不做什么

不出售个人信息，不收集通讯录、身份证、房产证明和精确定位，不在闲置广场中把居民信息用于抖店推广。

## 保存与删除

已出或下架物品会在运营规则规定的周期后归档；发布者可以联系管理员申请删除个人发布内容。为完成安全审计，必要的操作日志会在合理期限内保留。

## 第三方服务

正式接入 CloudBase、内容安全或微信能力前，应在微信公众平台配置真实的用户隐私保护指引，并按实际启用的接口补充第三方服务说明。本文件是项目草案，不能替代正式法律文本。
