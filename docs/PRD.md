# PRD：三湘邻里闲置 MVP

## 目标

在不收取佣金、不接触交易资金的前提下，替代群消息和腾讯文档，帮助小区居民快速发布、搜索、联系和下架闲置物品。

## 核心用户

- 发布闲置的社区居民
- 查找物品的社区居民
- 负责举报处理和规则维护的管理员
- 后续发布邻里福利的运营者

## MVP 范围

### P0

- 首页、分类、搜索、广场
- 发布物品、最多6张图片、价格和描述
- 我的发布、修改状态、下架
- 物品详情、复制联系信息
- 30天自动过期
- 发布即展示、基础敏感词拦截、举报处理
- 社区规则、安全提示
- 微信小程序正式版与 CloudBase 后端

### P1

- 微信身份与邀请码验证
- 图片云存储和压缩
- 图片内容安全检测
- 用户信任等级
- 举报处理工作台
- 数据导出和备份
- 邻里福利后台配置

### P2

- 求购专区
- 预约看货时间
- 合作商家福利
- 展示/点击统计
- 管理员交接和多小区配置

## 发布字段限制

前端和云函数对发布物品的输入字段做双重校验，限制一致：

| 字段 | 限制 | 说明 |
| --- | --- | --- |
| 物品名称 | 1–50 字 | 必填 |
| 物品描述 | 1–500 字 | 必填 |
| 价格 | 0–9999999.99 | 数字，0 表示免费 |
| 群内昵称 | 1–50 字 | 必填 |
| 楼栋 | 0–20 字 | 选填 |
| 联系信息 | 群昵称/微信号 1–50 字；手机号 1–11 位 | 必填，按联系类型区分 |
| 物品图片 | 1–6 张 | 必填 |

前端在输入框旁实时显示剩余字数；云函数在写入数据库前再次校验长度、价格合法性和图片数量。

## 成功指标

上线30天：20户使用、50件发布、10件标记已出、每周维护低于1小时、无重大投诉。

上线90天：50户使用、150件累计发布、每周持续新增、有效物品过期维护率持续改善。

## 非目标

第一年不做支付、订单、退款、物流、评价、站内聊天、实名、短信登录、精确定位和自动结算。

## 体验原则

- 发布尽量控制在1分钟内
- 首屏优先展示真实居民闲置
- 已出物品不出现在有效列表
- 商业内容永远单独、明确标识
- 任何不必要的个人信息不收集
