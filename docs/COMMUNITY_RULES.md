# 社区运营规则

## 群公告建议文案

> 三湘邻里闲置小程序用于本小区居民免费发布和查找闲置物品。平台不参与交易、不收取佣金。请如实描述物品并及时标记已预定/已出。交易请当面验货，不要提前转账。
>
> 小程序中的“邻里福利”如开放，将与居民闲置分开并明确标注推广内容。

## 管理员值班

建议设置1名主管理员和1～2名协助管理员。每天抽查待审核和举报，每周清理过期内容，每月做一次数据备份和费用检查。

## 处理时限

- 普通审核：24小时内
- 疑似诈骗/违禁：优先下架并联系发布者
- 举报：48小时内给出处理结果
- 用户封禁：保留原因和操作日志

## 处理原则

先保护社区安全，再考虑信息完整；对争议内容暂时下架，不在群里公开争吵；涉及人身或财产风险时建议用户向警方或相关部门求助。
